# 编辑海报 (edit-poster)

## 触发条件

当用户想要：
- 修改/编辑/调整已生成的海报
- 改文字、字体、颜色、位置
- 换背景、调排版
- "帮我改一下这张海报"

## 执行流程

### 1. 打开编辑器

调用 `open_poster_editor` Tool 打开已有的项目：

```json
{
  "tool": "open_poster_editor",
  "input": { "projectId": "用户提供的项目ID" }
}
```

### 2. 加载项目状态

调用 `project_state` Tool 加载已有项目：

```json
{
  "tool": "project_state",
  "input": {
    "action": "load",
    "projectId": "用户提供的项目ID"
  }
}
```

### 3. 引导用户编辑

告诉用户在编辑器中可以：
- **画布操作**：点击选中文字（蓝色边框高亮） → 拖拽调整位置 → 拖拽 8 个控制点调整大小（在约束区域内）
- **右侧属性面板（样式Tab）**：修改字体、字号、颜色（暖色系预设）、行间距、对齐方式
- **右侧属性面板（属性Tab）**：修改选中文字的内容
- **左侧文案面板**：打开左侧导航 📝 → 修改主标题、副标题等 5 个字段
- **版式切换**：打开左侧导航 🖼 → 点击缩略图切换不同版式
- **图层选择**：打开左侧导航 📑 → 从列表中选择文字元素
- **撤销重做**：Ctrl+Z（撤销）/ Ctrl+Shift+Z（重做）或顶部按钮

### 4. 保存与导出

编辑完成后：
- 自动保存（500ms 防抖）
- 点击"导出 PNG/JPG"按钮下载成品

## 注意事项

- 文字只能在预设的约束区域内拖拽，保证排版质量
- 修改文案后需重新选择版式以更新文字位置
- 自动保存到项目目录，关闭后可再次打开继续编辑
