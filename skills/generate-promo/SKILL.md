# 生成宣传图 (generate-promo)

## 触发条件

当用户想要：
- 生成/制作商品宣传图、产品推广图
- 为商品做AI宣传海报
- "帮我做一张商品宣传图""给这个产品做个推广图"
- "上传商品图片生成宣传海报"
- 制作带商品图的营销图片

## 执行流程

### 1. 打开编辑器

调用 `open_poster_editor` Tool 启动编辑器：

```json
{
  "tool": "open_poster_editor",
  "input": {}
}
```

编辑器打开后会自动进入仪表盘首页。点击右上角「+ 新建创作」按钮，在弹出浮层中选择「📦 商品宣传图」。

### 2. 引导用户准备素材

告诉用户需要准备：
- **商品图片**：清晰展示商品的 PNG/JPG/WebP 图片（≤10MB），拖拽或点击上传
- **商品特色描述**：描述商品的特点、卖点和期望的宣传图风格（≤500字）

示例描述：
- "一款简约风格的陶瓷咖啡杯，哑光白釉面，适合送礼。希望生成温馨简约风格的宣传图"
- "新款运动跑鞋，轻量化设计，透气网面。需要动感活力的电商风格宣传图"

### 3. 生成宣传图

用户上传商品图并填写描述后，点击「✨ 生成宣传图」按钮。

系统会：
1. 上传商品图到服务器（自动校验格式和大小）
2. 调用 `generate_promo_image` Tool 通过火山引擎豆包 Seedream 生成宣传图
3. 同时调用豆包大模型生成配套营销文案（标题、描述、卖点标签）

### 4. 审阅与导出

生成完成后展示：
- **宣传图**：AI 生成的商品宣传图
- **营销文案**：标题 + 描述 + 卖点标签

用户可以：
- 点击「🔄 重新生成」回到输入阶段调整参数
- 点击「📤 导出 PNG」或「📤 导出 JPG」下载成品
- 点击「← 返回仪表盘」回到作品列表

### 5. 返回仪表盘

宣传图项目自动保存，返回仪表盘后可在作品卡片中看到（带绿色「宣传图」标签）。点击卡片可重新打开查看。

## 注意事项

- 宣传图使用火山引擎豆包 Seedream 4.5 模型（文生图）
- 文案由火山引擎豆包大模型生成（可通过 ARK_TEXT_MODEL 指定端点）
- 生成时间约 10-30 秒
- 支持 PNG/JPG 导出
- 不提供画布编辑（与海报不同）
- 需要 ARK_API_KEY 环境变量（火山引擎 ARK）

## 常见场景话术

用户说："帮我做个咖啡杯的宣传图"
→ 引导上传杯子照片 + 描述风格和卖点

用户说："给这个产品做个电商推广图"
→ 引导上传产品图 + 填写"电商促销风格，突出性价比和限时优惠"

用户说："我要发朋友圈宣传新品"
→ 引导上传商品图 + 描述"朋友圈分享风格，温馨生活化"
