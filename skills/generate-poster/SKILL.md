# 生成海报 (generate-poster)

## 触发条件

当用户想要：
- 创建/生成/制作海报
- 设计宣传图、推广图、活动海报
- 为产品、活动、节日制作图片
- 输入描述生成图片

## 执行流程

### 1. 打开编辑器

调用 `open_poster_editor` Tool 启动 Web 编辑器：

```json
{
  "tool": "open_poster_editor",
  "input": {}
}
```

浏览器会打开 AI 海报编辑器，默认进入仪表盘首页。点击右上角「+ 新建创作」按钮，在弹出浮层中选择「🎨 海报制作」进入海报生成流程。

### 2. 引导用户输入

告诉用户在编辑器中央的暖色渐变向导卡片中输入：
- **海报主题**：例"618大促"、"新品上市"、"中秋活动"
- **使用场景**：例"朋友圈推广"、"门店展示"
- **风格偏好**：简约、高级、活泼、商务、国风等（分段控件选择）
- **海报尺寸**：竖版(1080×1920)、横版(1920×1080)、方形(1080×1080)
- **参考图**（可选）：拖拽上传参考海报让 AI 复刻风格

### 3. 生成文案

调用 `generate_copy` Tool：

```json
{
  "tool": "generate_copy",
  "input": {
    "requestId": "req-xxx",
    "params": {
      "theme": "用户填写的主题",
      "scene": "用户填写的场景",
      "style": "用户选择的风格"
    }
  }
}
```

返回的文案包含：主标题、副标题、引流短句、活动信息、底部备注。

### 4. 生成海报底图

调用 `generate_poster_images` Tool：

```json
{
  "tool": "generate_poster_images",
  "input": {
    "requestId": "req-xxx",
    "params": {
      "style": "用户选择的风格",
      "size": { "width": 1080, "height": 1920 }
    }
  }
}
```

系统会并行生成 8 种版式的纯净无文字海报底图。

### 5. 用户操作

v0.2 采用暖色活泼风格（warm-playful），两阶段布局：

**生成阶段**：
1. 在中央渐变向导卡片中填写需求
2. AI 生成文案后显示在卡片中
3. 点击「生成 8 种版式底图」
4. 在 4 列卡片网格中查看生成的底图
5. 点击卡片放大预览
6. 点击「开始编辑」进入编辑阶段

**编辑阶段**：
1. 点击左侧导航图标打开版式列表/文案/图层/导出面板
2. 在画布上拖拽调整文字位置（蓝色选中边框 + 8 控制点）
3. 在右侧 Tab 式面板修改属性（内容）或样式（字体/颜色/大小/行间距/对齐）
4. 点击顶部或左侧导出按钮「导出 PNG/JPG」下载成品
5. 支持 Ctrl+Z/Ctrl+Shift+Z 撤销重做

## 注意事项

- 文案和底图是独立生成的，文案精准无乱码
- 底图纯净无文字，文字全部由系统嵌入
- 用户可在预设区域内自由拖拽微调文字
- 自动保存项目状态，支持二次编辑
- 需要 ARK_API_KEY 环境变量（火山引擎 ARK）

## 常见场景话术

用户说："帮我做个促销海报"
→ 引导填写主题、场景、风格，然后依次生成文案和底图

用户说："做个中秋活动海报"
→ 主题="中秋活动"，场景="门店促销/朋友圈"，风格="国风/简约"

用户说："我要做个产品宣传图"
→ 主题="产品名称"，场景="电商/朋友圈"，风格="简约/高级"
